# 中华人民共和国职业分类大典(2022年版)—— 公示稿→正式版→现行 全版本链开源数据

非官方整理。本仓库把《中华人民共和国职业分类大典(2022年版)》的**公示稿基线、正式版底库、2024/2025/2026 三批增量、以及现行有效库(1,687 职业)**整理成一套可机器复算、账目完全闭合的结构化数据,并附完整方法论与官方文件凭证。

> **最终依据**:本仓库一切数据均为整理件。**《中华人民共和国职业分类大典(2022年版)》以国家正式出版的纸质文本为最终版本、最终依据**;任何数据(含本仓库各 CSV/JSON)如与国家纸质文本不符,一律以纸质文本为准。
>
> **免责声明**:本仓库为非官方整理,与人力资源和社会保障部等发布机关无任何隶属或背书关系。商用请自行评估官方来源的相关使用约束。

## 版本链与账目

```
公示稿(2022-07, 1,636 职业/L133/S97)
   │  diff: +6 新增 −3 移除,移码 7 组、改名 8 处  → data/gap_gongshi_to_official.csv
   ▼
正式版(2022-09-27 颁布, 人社部发〔2022〕68号, 1,639 职业/L134/S97/双标23)
   │  + 人社厅发〔2024〕36号(新增19) + 〔2025〕26号(新增17) + 〔2026〕35号(新增11)
   │  + 烟机钳工上升为职业(2025批,不计入新增数)
   ▼
现行有效库(1,687 职业,官方发布的现行职业数据整理快照)
```

三条账目均可由 `scripts/03_diff_gongshi_official.py` 机械化复算,全部 PASS:

- 1,636 + 6 − 3 = **1,639**(官方正式版口径,四数全中:1,639/L134/S97/双标23)
- 1,639 + 47 + 1 = **1,687**(现行库实测,码集逐一相等)
- 公示稿 1,636 码集与公示稿 PDF 原文**全集等价**(1,636/1,636)

## 字段说明

- 职业表(CSV):`careerCode`(大典编码,如 `2-02-27-07`)、`careerName`(名称,尾部 `L`=绿色职业、`S`=数字职业、`L/S`=双标,与官方标注一致)
- 层级表:`level`(1=大类, 2=中类, 3=小类)、`parentCode`
- 差异表:`changeType`(新增/移除/移码/改名/批次移码/批次改名/升职)、变更前后码名

## 数据来源(文号引用)

- 《中华人民共和国职业分类大典(2022年版)》,人社部发〔2022〕68号(2022-09-27 颁布)
- 增量批次:人社厅发〔2024〕36号、人社厅发〔2025〕26号、人社厅发〔2026〕35号(通知正文与附件原件在 `sources/`)
- 公示稿基线:2022 年 7 月《中华人民共和国职业分类大典(2022年版)(社会公示稿)》(官方公示文件),码集经公示稿 PDF 原文逐码核验
- 现行有效库:据官方公开发布的职业分类现行数据整理(2026-11-11 快照)

## 复现

```bash
pip install pymupdf
python scripts/02_rebuild_official.py        # 从现行库快照回滚重构正式版 + 四口径验版(assert)
python scripts/03_diff_gongshi_official.py   # 三条账目复算(全部 PASS)
```

说明:`data/dadian2022_current_1687.csv` 为快照数据,`02` 从该快照回滚出正式版;若官方后续发布新批次,更新快照并按新增批次文号扩展 `02` 的回滚清单即可。

## 已知边界

- 正式版底库为**机器重构**(现行快照回滚),未与正式版纸书逐字比对;官方四口径(总数/绿色/数字/双标)与批次增量逐条对账全部通过,推断声明见 `docs/gap-report-gongshi-vs-official.md` §五。**如与国家纸质文本不符,以纸质文本为准。**
- 公示稿 PDF 全文与正式版纸书排版件受出版社排版权约束,本仓库**只发布结构化数据**,不托管全文 PDF。
- 名称尾部的 L/S 标注在不同载体间存在空格级差异(如"网络主播 S"与"网络主播S"),属载体排版差异,非内容差异。
